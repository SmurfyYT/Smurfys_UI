# Smurfy's UI

Paste this into your executor:

```lua
loadstring(game:HttpGet('https://raw.githubusercontent.com/SmurfyYT/Smurfys_UI/refs/heads/main/version_1.0'))()
```

Works on PC, phone and tablet.
- **PC:** press **RightShift** to open or close the menu (or click the logo to minimize it).
- **Phone / tablet:** tap the round **S** button. The Buttons tab adds on-screen buttons like Fly.
